# CBETA 数据支持与功能说明

[返回项目首页](../README.md)

Smart Library 为 CBETA 数据提供专门的目录、检索、经文排版、校注异文与引用定位支持，并将这些能力接入统一的阅读和笔记工作区。既可以通读经论，也可以按关键词、书目属性或文献出处查找内容，再将阅读所得整理成自己的笔记。

**标题快搜与全文搜索默认跨知识库。** CBETA 可以和个人笔记、本地文献、ZIM 离线资料一起查询；需要集中查考时，也可以将范围限定到 CBETA、某个部类、一部经或多个选定节点。

## 接入数据与浏览目录

- 支持直接绑定 `bookcase.zip`，也支持已经解压的数据目录。
- 绑定时可选择「簡易」「進階」「部類」中的一棵官方目录树，默认使用部類目錄。
- 数据包中另行加入的受支持 HTML 资料树，也可以作为独立知识库同时绑定、建立索引和参与跨库搜索。
- 经文按卷打开，配合经内目次、卷导航及目录树定位，在书目结构与阅读位置之间切换。
- CBETA 源数据只读；书签、收藏、标签及自定义属性由程序另外保存。

开始使用：

1. 在左侧目录区绑定 CBETA 数据包或目录，选择目录树。
2. 在知识库上右键「建立索引」，完成后即可进行全文搜索。标题快搜独立于全文索引。
3. 按 `Ctrl+G` 或双击 `Shift` 查标题，按 `Ctrl+H` 查全文。

官方三棵目录树对应同一份经文数据，绑定时只选一棵。若要更换，需先解除绑定再重新绑定。

## 检索：从记得的词句找到经文

### 全文搜索

- **宽松匹配**：适合用记得的词句片段组合查找。中文查询按相邻二字组合匹配，要求各组合都出现在同一卷中，但不要求相邻；空格可以分隔多个关键词。这是文字匹配，不是语义搜索。
- **精确短语**：按连续短语查找，可忽略标点差异，适合核对具体字句。
- **繁简互查**：输入简体或繁体均可检索，同时处理全半角、大小写及部分异体字差异；检索归一化不改写源数据。
- **原文定位**：结果提供带高亮的上下文片段及原书行号，点击后打开对应卷，跳转并高亮命中内容。
- **书内检索**：阅读时选中文字，可直接全文检索、精确检索或检索本书，也可在当前阅读页内查找。

全文检索以「卷」为内容单位。命中表示这一卷包含符合条件的文字，结果片段用于继续定位具体位置。

### 范围与书目筛选

可通过目录树的「从这里搜索标题」「从这里搜索全文」，或将节点加入搜索范围，限定到部类、经或其他目录节点；也支持多个节点组合范围。

对具有相应元数据的经籍，搜索结果可按以下维度筛选：

| 维度 | 用途 |
| --- | --- |
| 部类 | 按目录中的文献分类缩小范围 |
| 时域 | 按朝代等时间属性筛选 |
| 人物 | 按作者、译者等关联人物筛选 |
| 藏经 | 按所属藏经筛选 |
| 典类 | 按经、律、论及其他文献类型筛选 |

各维度可多选。同一维度中满足任一所选值即可，不同维度之间需同时满足。筛选列表支持查找与排序，方便在较长的人物、分类列表中定位。

### 标题快搜

标题快搜覆盖经名、经内目次与卷，不必逐层展开目录。可以组合输入经名、经号、作译者和目次中的关键词，查找具体的序、品、章或卷。

标题匹配支持繁简、全半角和标点归一化，可选拼音首字母检索；也可以为节点添加别名，便于用常用简称查找。默认搜索所有知识库，选择 CBETA 标签后可集中查看经籍结果。

## 引用定位：从出处直接回到正文

在标题快搜框中输入 `#`，可以查看 CBETA 定位格式。常用形式包括：

| 输入 | 定位目标 |
| --- | --- |
| `#T0001` | T0001 的第一卷 |
| `#T0001_001` | T0001 的第一卷 |
| `#T0001_p0001a01` | T0001 的指定页、栏、行 |
| `#T01n0001_p0001a01` | 同时指定册号、经号与行号 |
| `#T01, no. 1, p. 1a1` | 按引用格式定位 |

也可以直接粘贴 CBETA「复制为引用」得到的文字。程序识别其中的出处，提供跳转入口；如果引用中包含引文，会尝试在对应卷中查找该段文字，找到后跳转并高亮。

这也照顾到一种实际情况：引用标注的是卷首位置，而引文出现在卷中其他地方。程序可以结合出处和引文继续定位。

阅读时可选择「复制文字（&引用出处）」，将选文与 CBETA 版本、册号、经号、页栏行等出处信息一起复制。

## 经文排版与阅读导航

- **段落版式**：保留段落、标题、偈颂、科判、表格、图片等结构，适合连贯阅读。
- **原书行版式**：按原书分行显示，方便对照页栏行；两种版式均支持搜索命中高亮与定位。
- **经内目次与卷导航**：从目次进入对应内容，也可在同一部经的各卷间切换。
- **繁简显示切换**：仅改变阅读显示，源文档和索引保持原有内容。
- **底本读法**：在支持的位置显示底本（如大正藏）的读法，便于与 CBETA 修订后的正文对照；该切换只影响显示，检索仍依据默认正文。
- **缺字与悉昙字显示**：根据数据中的字符信息显示缺字；普通字体无法显示的私用区字符可显示组字式，悉昙字可显示转写，并提供缺字标识提示。
- **字体与版面调整**：可调整字体、字号、行距和明暗主题。

## 编注、校勘与异文

段落版式提供六种编注显示方式，可按阅读需要调整信息密度：

| 方式 | 显示与交互 |
| --- | --- |
| 无 | 隐藏编注标记，集中阅读正文 |
| 原编注 | 将底本原编注以小字嵌入正文 |
| CB编注 | 将 CBETA 编注嵌入正文，没有时使用原编注 |
| 数字标 | 显示编注序号，悬停查看 CBETA 编注 |
| 着色 | 为有其他读法的文字着色，悬停查看编注、正文读法和其他版本读法 |
| 着色+原编注 | 在着色方式的提示中同时提供原编注 |

异文浮层将版本与读法对齐展示，便于逐项对照；多个版本共用同一读法时合并显示。浮层中的文字可以选中复制。

只有编注、没有对应着色文字的位置仍提供编注入口。整段异文按正文结构显示，避免把整段内容变成一个难以阅读的悬停提示。

## 多文献对照与阅读恢复

- 一卷一个阅读标签，可将不同经卷左右或上下分栏，也可以浮动或弹出为独立窗口。
- 搜索页可以与经文并排，在查看结果的同时阅读上下文。
- 再次打开同一卷时切换到已有阅读页；通过搜索或引用打开时，跳转到目标位置。
- 切换标签保留阅读位置，重启后可恢复阅读标签、布局与进度。
- 从阅读标题或标签菜单定位到目录树，方便确认当前经卷所属位置。
- 最近访问用于回到读过的内容；目录中「曾经打开过」的标记只表示访问过，不表示已经读完。

## 从阅读到个人整理

阅读中选中文字，可以收藏、加标签、加入笔记或追加到今日记。摘录保留文献标题、作译者及来源位置，并附回到原文的链接；回看笔记时可以重新进入经文。

脑图可用于组织摘录与思路，白板可用于整理关系；它们与个人笔记一起参与知识库检索。需要查词时，可使用自行添加的本地词典或拼音工具。启用并配置 AI 助手后，也可将选文和引用资料加入对话。

书目节点还可以维护别名、标签和筛选属性，用自己的整理方式补充现有目录与元数据。

### 专题资料的导出、分享与备份

可将选定节点或整个知识库导出为 `.smartlib` 包，供备份、迁移或分享使用。对于自己的笔记和专题整理，可以将数据包交给其他用户导入。

CBETA 内容导出时按卷转换为 Markdown，并保留目录层级；编注、异读和梵汉对照等内容转为脚注。导入后成为可编辑的内部知识库，适合进一步整理。转换后的笔记库不再提供 CBETA 原数据源专属的经号及引用定位功能；源资料中的图片目前以 `[图]` 占位，着色等显示信息也不随 Markdown 保留。

## 数据与使用说明

CBETA 数据需自行准备，不随程序安装包附带。现有开发与验证记录主要使用 2025.Q1 数据包。

程序的开源许可与资料本身的授权分别适用。使用、导出或分享 CBETA 内容时，请遵守数据提供方的授权条款。

程序下载、平台支持与通用功能见 [项目首页](../README.md)，实现设计与数据格式说明见 [设计规范](design-spec.md)。
